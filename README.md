# 🔬 病理学识图复习 — Patho Pic Reviewer

人体概论实验课 · 病理图片考试题库复习工具。

## 功能

- **随机识图考试** — 每次展示一张病理图片，输入诊断答案
- **智能模糊匹配** — 支持别名、子串、字符序列匹配，如答"头皮鳞状上皮癌"能匹配标准答案"头皮鳞癌"
- **三轮渐进提示** — 点击💡按钮获得知识点提示，不直接给出答案
- **错题本系统** — 记录每题做错次数，支持仅复习错题模式
- **轮次复习** — 做对的题本轮不再出现，做错的题权重升高多次出现
- **知识点解析** — 每题答后展示详细解析（来源于课堂笔记+补充知识）
- **多轮持久化** — 所有记录保存在浏览器 localStorage
- **108题 × 4分类** — 血循障碍、炎症、肿瘤、组损与修复
- **图片缩放** — 点击图片放大查看细节
- **响应式设计** — 桌面和手机端双适配

## 快速开始

### 方式一：本地服务器（推荐）

```bash
cd webapp
python3 -m http.server 8765
```

浏览器打开 `http://localhost:8765`

### 方式二：VS Code Live Server

用 VS Code 打开 `webapp` 文件夹，右键 `index.html` → "Open with Live Server"

### 方式三：直接打开

直接双击 `index.html`，部分浏览器可能因跨域限制无法加载题库数据，推荐使用方式一或二。

| 快捷键 | 功能 |
